4. Information We Collect

हमारे App में कई features हैं और हर feature को चलाने के लिए अलग-अलग जानकारी चाहिए। नीचे हम हर category की पूरी जानकारी दे रहे हैं।

4.1 Personal Identification Information

  • Full name (आपके द्वारा भरा गया या Google Sign-In से)
  • 10-digit mobile number (primary identifier — OTP और account recovery के लिए)
  • Email address (optional — Google Sign-In से या मैन्युअल)
  • Password (आपके द्वारा चुना गया, हमारे secure database में access controls के साथ सुरक्षित)
  • Profile photo और cover photo (optional)

4.2 Location Information

  • Profile location: State, District, Tehsil, Block, Village (आपके द्वारा भरा गया)
  • GPS coordinates (latitude/longitude): केवल तब collect होते हैं जब आप उपयोग करते हैं:
    • 🌾 भूमि मापन (Land Measure) — खेत की सीमा मापने के लिए
    • 🚜 ट्रैक्टर डायरी (Tractor Diary) — खेत की location record करने के लिए
    • 🌦️ मौसम (Weather) — स्थानीय मौसम दिखाने के लिए
  • Background में location कभी नहीं collect होती। केवल आपकी action पर।

4.3 Financial & Transaction Information

जब आप हमारे financial tools का उपयोग करते हैं, तो हम store करते हैं:

  • उधारी खाता (Udhaari Khata): व्यक्ति का नाम, फ़ोन, गाँव, रकम, ब्याज दर, तारीखें, payment status
  • मंडी कैलकुलेटर (Mandi Calculator): फसल का नाम, मात्रा, भाव, कटौतियाँ, शुद्ध रकम
  • दुकान बिल (Shop Bill): ग्राहक की जानकारी, items, GST, छूट, coupon codes
  • ट्रैक्टर डायरी (Tractor Diary): ग्राहक की जानकारी, काम का प्रकार, डीज़ल खर्च, मज़दूरी, payment status
  • ग्लोबल बजट (Global Budget): आय और खर्च की entries
  • मजदूर हाजिरी (Labor Attendance): मजदूरों के नाम, फोटो, रोज़ी, हाजिरी, payment records
⚠️ ज़रूरी: यह financial data पूरी तरह आपका private data है। यह केवल आपके local device (SQLite database) और आपके Firebase account की private collection में store होता है। यह किसी दूसरे user, दुकानदार या third party के साथ कभी share नहीं होता।

  • क्या collect होता है: Advertising ID (resettable), device type, सामान्य location (city-level), ad interaction data
  • उद्देश्य: प्रासंगिक ads दिखाना और ad performance मापना
  • किसे मिलता है: Google AdMob (और उसके advertising partners)
  • आपका control: आप personalised ads से opt-out कर सकते हैं: Settings → Google → Ads → "Delete advertising ID" या "Opt out of Ads Personalisation"

  • कौन सी screens देखी गईं: जैसे "forum", "mandi_bhav", "crop_encyclopedia"
  • Feature usage counts: anonymous aggregates
  • Session duration: App कितनी देर खुला रहा
  • Custom events: post create, coupon generate, referral भेजना, आदि

  • केवल आपके device तक notifications पहुँचाने के लिए use होता है
  • कभी भी बंद कर सकते हैं App Settings → Notifications से

4.15 Local Storage

  • Local cache (images और videos के लिए — logout पर अपने आप clear हो जाता है)

सारा local data logout करने या App uninstall करने पर अपने आप delete हो जाता है।

Advertising ID क्या है?

Google Advertising ID (GAID) Android द्वारा आपके device को दिया गया एक unique, resettable identifier है। यह advertising के लिए use होता है और आपकी personal identity (नाम, फ़ोन, ईमेल) से जुड़ा नहीं होता।

हम इसका उपयोग कैसे करते हैं

  • आपकी रुचियों और सामान्य location के अनुसार ads दिखाना
  • Ad performance मापना (impressions, clicks, conversions)
  • Ad fraud रोकना

आपका Control

आप अपने Android device से ad personalisation control कर सकते हैं:

  • Advertising ID Reset करें: Settings → Google → Ads → Reset advertising ID
  • Personalised ads से opt-out: Settings → Google → Ads → Delete advertising ID
  • Ad-Free में upgrade करें: Premium subscription खरीदें
⚠️ ध्यान दें: अगर आप opt-out करते हैं, तो भी आपको ads दिखेंगे — पर वे non-personalised होंगे (केवल सामान्य context पर आधारित)।

14. Storage & Security

हम industry-standard security measures का उपयोग करते हैं:

  • Encryption in transit: सारा data HTTPS/TLS के through भेजा जाता है
